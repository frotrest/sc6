# ⚡ SC6 Project

Учебный/демонстрационный проект, собранный на базе **Vite**, с использованием HTML, CSS и JavaScript.

## 📖 Описание

Репозиторий содержит базовую структуру фронтенд‑приложения.  
Основная цель — показать настройку окружения, линтеров и форматтеров, а также базовую организацию кода.

## 📂 Структура проекта

```
CI/CD конфигурации ├──  .github/workflows
Статические файлы ├── src/
Настройки Prettier  ├── .prettierrc
Настройки ESLint ├── eslint.config.js
Конфигурации ├── package.json
Зависимости и скрипты ├── package-lock.json
Конфигурация Vite └── vite.config.js
```

## 🛠️ Технологии

- **HTML (52.1%)** — основная разметка
- **CSS (35.1%)** — стилизация
- **JavaScript (12.8%)** — логика приложения
- **Vite** — сборка и запуск проекта
- **ESLint + Prettier** — линтинг и форматирование кода

## 🚀 Установка и запуск

```bash
# Клонируем репозиторий
git clone https://github.com/frotrest/sc6.git
cd sc6

# Устанавливаем зависимости
npm install

# Запускаем проект
npm run dev


📦 Скрипты
- npm run dev — запуск dev‑сервера
- npm run build — сборка проекта
- npm run format - форматирование кода с помощью Prettier
- npm run lint — проверка кода ESLint
```
